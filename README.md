# SafeBuild

Local-first security auditing and safe auto-healing toolkit by RC Empire.

> Status: initial scaffold in progress. Security findings are advisory until independently verified.

## Run

- `npm install`
- `npm start` — launch the local desktop app
- `npm run dev:web` — run the browser UI for development

See `README_RC_EMPIRE.md` for setup, privacy notes, supported scans, and deployment guidance.
